# 2026-dslr
Recreation of the Hogwarts Sorting Hat using logistic regression.

## Working in Linux
If using Windows, use WSL to run the project

## Instalación
make
source venv/bin/activate
make deps

## Estructura
Data visualization
describe.py

Graph scripts
histogram.py
scatter_plot.py
pair_plot.py

Logistic regression
logreg_train.py
logreg_predict.py
